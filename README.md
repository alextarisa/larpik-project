##  Larpik.pl – LARP Management Platform
A comprehensive web application designed to streamline the organization and management of LARP (Live Action Role-Playing) events. This project was developed as a Bachelor’s Engineering Thesis.
 Live Demo: [larpik.pl](https://larpik.pl)
##  Project Overview
Larpik.pl is a dedicated tool for the LARP community, allowing organizers to manage events and participants in one place. The project focuses on high usability and clear interface design to handle complex event data.
##  My Roles & Responsibilities
As a co-creator and developer, I was responsible for both the creative and technical aspects of the project:

* System Design: Defined core functionalities and system architecture.
* UX/UI Design: Created complete interface designs in Figma, ensuring an intuitive experience for RPG enthusiasts.
* Project Management: Managed tasks and maintained communication with the client to meet project requirements.
* Database Design: Planned the relational database structure to handle event and user data efficiently.
* Frontend Development:
* Implemented static pages and the global footer.
   * Developed the User Profile view.
   * Ensured full Responsiveness (RWD) across all devices.
* Maintenance: Bug fixing and performance optimization.

## Tech Stack

* Frontend: Next.js / React, Material UI (MUI)
* Design: Figma
* Backend/Database: Firebase
